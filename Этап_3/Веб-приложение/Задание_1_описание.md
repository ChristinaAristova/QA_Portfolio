# Задание 1: Проверка запросов и ответов

## Описание проекта

Знакомство с инструментом DevTools для анализа клиент-серверного взаимодействия на примере дымового тестирования форм регистрации и авторизации интернет-магазина InterShop.

### Цель

Проанализировать работу старшего коллеги-тестировщика, изучить процесс использования DevTools для тестирования и составить универсальный алгоритм для решения аналогичных задач в будущем.

### Используемые инструменты

* **DevTools** (анализ сетевых запросов, статусов ответов, заголовков)
* **Браузер** (тестирование веб-интерфейса)
* **YouGile** (система баг-трекинга для фиксации дефектов)

### Ключевые результаты и достижения

* **Освоение DevTools для тестирования:** Изучен процесс анализа HTTP-запросов и ответов через вкладку Network, включая отслеживание статус-кодов, времени выполнения и заголовков.
* **Систематизация подхода:** Разработан пошаговый алгоритм тестирования с использованием DevTools, включающий этапы анализа запросов и фиксации багов.
* **Понимание клиент-серверного взаимодействия:** Сформировано понимание структуры HTTP-запросов и ответов, роли серверной части в обработке данных.
* **Обратная связь:** Работа выполнена верно и принята преподавателем.

### Освоенные навыки

* Работа с вкладкой Network в DevTools для анализа сетевых запросов
* Отслеживание статус-кодов HTTP-ответов
* Анализ структуры запросов и ответов (payload, headers)
* Формализация процесса тестирования через алгоритмы
