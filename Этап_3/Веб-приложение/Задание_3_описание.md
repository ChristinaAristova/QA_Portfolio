# Задание 3: Тестирование витрины (главная страница, каталог, карточки товаров, корзина)

## Описание проекта
Комплексное тестирование витрины интернет-магазина InterShop: проверка главной страницы, каталога, карточек товаров и корзины с анализом запросов и оценкой трудозатрат.

### Цель
Протестировать ключевые модули витрины (главная, каталог, карточки товаров, корзина), проверить запросы и ответы в DevTools, оценить и зафиксировать трудозатраты на тестирование.

### Используемые инструменты
* **DevTools** (вкладка Network для анализа запросов и ответов)
* **YouGile** (система баг-трекинга)
* **Google Таблицы** (шаблон тест-кейсов, фиксация статусов и времени)
* **Техническая спецификация** (обновлённая версия)

### Ключевые результаты и достижения
* **Разработка тестовых сценариев:** Составлено 30–40 тест-кейсов, охватывающих всю функциональность витрины: поиск товара, каталог, карточку товара и корзину. Шаги и ожидаемые результаты сформулированы максимально конкретно.
* **Анализ запросов и ответов:** С помощью DevTools (Network) проверены запросы при загрузке страниц, корректность данных в ответах и статус-коды.
* **Оценка трудозатрат:** Проведена реалистичная оценка планируемого и фактического времени выполнения тестов (округление до минут). Данные занесены в таблицу.
* **Оптимизация тест-кейсов:** Удалось сократить количество проверок без потери качества покрытия функциональности.
* **Фиксация результатов:** По итогам тестирования проставлены статусы (Passed, Failed, Blocked) для всех тест-кейсов, баги зафиксированы в YouGile и прилинкованы к карточке тестирования.
* Обратная связь:** Работа выполнена верно и принята преподавателем.

### Освоенные навыки
* Написание тест-кейсов для сложных модулей интернет-магазина (главная, каталог, карточки, корзина)
* Анализ сетевых запросов через DevTools (Network) для проверки корректности данных и статус-кодов
* Оценка трудозатрат на тестирование (планирование и фактическое время)
* Оптимизация тестового покрытия: сокращение количества проверок без потери качества
