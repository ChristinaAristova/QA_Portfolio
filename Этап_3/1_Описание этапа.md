# Этап 3: Тестирование клиент-серверной архитектуры

В рамках третьего этапа обучения на базе проектов SkillCinema и InterShop были изучены и применены ключевые аспекты тестирования клиент-серверного взаимодействия.

### Ключевые навыки:

- **Клиент-серверное взаимодействие:** Понимание принципов работы веб-приложений, структуры HTTP-запросов и ответов, роли серверной части в обработке данных.
- **Тестирование API:** Освоение инструментов для отправки запросов (Postman / аналоги), проверка корректности ответов сервера, анализ статус-кодов и структур данных (JSON/XML).
- **Тестирование бэкенда:** Проверка логики обработки данных на серверной стороне, включая валидацию, авторизацию и обработку ошибок.
- **Взаимодействие с базами данных (начальный уровень):** Понимание структуры баз данных, выполнение простых SQL-запросов для проверки данных и выявления ошибок.

### Инструменты:

- **YouGile** (система баг-трекинга)
- **Postman** (для тестирования API-запросов)
- **DevTools** (анализ сетевых запросов)
- **Google Документы/Таблицы** (тестовая документация)

### Дополнительные аспекты:
- Работа с требованиями к API и их анализ.
- Понимание различий между REST и SOAP (при необходимости).
- Навыки отладки клиент-серверного взаимодействия через логи и инструменты разработчика.
- Тестирование требований (аналитики) — навык проверки корректности и полноты спецификации.
